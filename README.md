## Conventions

- **Git LFS** is enabled for `*.png`, `*.pdf`, `*.jpg`. Before cloning, run `git lfs install`. Without LFS, image and PDF files clone as ~130-byte pointers, not real assets.
- **Brand voice** lives in `bloom_soft_co_brand_guidelines.pdf`. Chloe is the principal voice — nothing customer-facing publishes without her sign-off.
- **Launch artifacts** at the root (`LAUNCH-TONIGHT.html`, `chloes-launch-guide.html`, `chloes-week-1-playbook.html`, `bloom-soft-gtm-sprint.html`) are local-view HTML — not deployed.
- **Listing copy** = the `conference-*.md` files at the root plus `listings/etsy/`. Copy-paste ready for Etsy.
- **Product PDFs are generated, not edited.** To change content, edit the script in `scripts/` and re-run.

## Generating a product PDF

```bash
# One-time, if you have not yet:
git lfs install
pip install reportlab pillow   # check each script header for its actual deps

# Build the Conference Passport (kids product)
python scripts/generate-kids-passport.py

# Build the Conference Revelation System (adult product)
python scripts/generate-revelation-system.py
```

The scripts write their output PDFs to the repo root or `products/conference/` — confirm in the script header before running.

## Hard rules

- **Never publish to Etsy, Redbubble, or any storefront from this repo.** Drafts only — Chloe (or Caleb on her behalf) does the publish step.
- **Never push social copy directly to TikTok, Instagram, or anywhere else.** Drafts only.
- **Brand assets stay inside the repo.** No reposting Bloom Soft Co. prompts, product copy, or PDFs outside this project.
- **AI image generation** runs on Chloe's side — the scripts here produce prompts and PDFs; image generation against Imagen 3 (or any other model) happens outside this repo so Chloe controls seed, variation, and output.
