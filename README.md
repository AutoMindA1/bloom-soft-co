# 🌸 Bloom Soft Co.

Soft watercolor art for homes and hearts. Digital downloads you can print today.

Bloom Soft Co. creates gentle, watercolor-inspired digital art and printables for families who love beauty and meaning. Every design is crafted with soft botanicals, wildflower palettes, and a cottagecore aesthetic — for walls, journals, and family moments that deserve something beautiful.

---

## 📦 What's in This Repo

This repository contains all the creative and operational assets for the Bloom Soft Co. shop — product copy, AI image prompts, listing files, PDF generation scripts, brand assets, and marketing guides.

## 🚀 Getting Started (For Shop Updates)

1. **Generate art** — Use prompts in `prompts/imagen3/` and `gemini-imagen3-batch-prompts.md` with [Gemini](https://gemini.google.com) to create product images.
2. **Generate PDFs** — Run scripts in `scripts/` to build printable products.
3. **Prepare listings** — Copy titles, descriptions, and tags from `product-pipeline-batch.md` or `conference-products-listings.md`.
4. **Upload to Etsy** — Follow the step-by-step guide in `LAUNCH-TONIGHT.html`.
5. **Market on TikTok** — Use scripts from `chloes-tiktok-scripts.html`.
